## 🗺️ Ta Roadmap "Identity Architect"

### Module 1 : Les Fondations & La Structure (L'Annuaire)

- **Objectif :** Comprendre comment on range les identités avant de les sécuriser.
    
- **Concepts :** LDAP vs SQL, Arborescence, RBAC (Rôles) vs ABAC (Attributs).
    

### Module 2 : La "Langue" de l'IAM (Les Protocoles)

- **Objectif :** Maîtriser les échanges entre les machines.
    
- **Concepts :** Kerberos (le vieux sage), SAML (le passeport XML), OAuth2 & OIDC (le standard moderne / Tokens).
    

### Module 3 : L'IAM Hybride & Cloud

- **Objectif :** Passer du serveur local à l'infrastructure mondiale.
    
- **Concepts :** Microsoft Entra ID (ex-Azure AD), Synchronisation d'identités, Accès conditionnel (Zero Trust).
    

### Module 4 : Le "Garde du Corps" (Le PAM - Privileged Access Management)

- **Objectif :** Sécuriser les comptes qui ont le droit de tout casser.
    
- **Concepts :** Vaults, Bastions, Just-In-Time (JIT) Access.
    

### Module 5 : Automatisation & Gouvernance (IGA)

- **Objectif :** Gérer des milliers d'utilisateurs sans transpirer.
    
- **Concepts :** Workflow de provisionnement, Revues d'accès, Cycle de vie (Joiner/Mover/Leaver).
